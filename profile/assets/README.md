letters of the name and the six research pillars, the ring is the company, and the two

technical captures. No stock photography, no illustration.

Export both from `Qomira GitHub Banner.dc.html` in the design project. The banner sits on
ink, so it reads correctly against both GitHub light and dark themes without a second file.
