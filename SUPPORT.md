# Support

| What you need | Where to go |
|---|---|
| A bug in this code | Open an issue in the repository it affects |
| A question about how something works | The repository's Discussions tab |
| A question about a paper or a model | research@qomiralabs.com |
| Something wrong with Juncta | [juncta.xyz](https://juncta.xyz) and its own support channel |
| Something wrong with CelerFi | [celerfi.network](https://celerfi.network) and its own support channel |
| A security vulnerability | security@qomiralabs.com. See `SECURITY.md`, not an issue |
| Press, partnerships, brand assets | brand@qomiralabs.com |
| Anything else | hello@qomiralabs.com |

Product problems are genuinely faster through the product's own channel. The people who can
fix a Juncta issue do not read this organisation's issues.

We are a small team. Issues in active repositories get a first response within about
**5 business days**. Research correspondence can take longer, and we would rather answer
properly than quickly.
